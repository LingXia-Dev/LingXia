# LingXia 0.25.1

## Breaking changes

### refuse what `lingxia install` cannot install instead of reporting success

BREAKING: `lingxia install` now fails on macOS and Windows instead of exiting 0 without installing anything; open the `.app`/`.dmg` or run the Windows installer or `.exe` directly. Install onto iOS also takes an `.ipa`, a `.app`, or a `lingxia package` `dist/ios` directory, and signs a copy rather than the build output.
