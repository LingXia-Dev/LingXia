# LingXia 0.28.0

## Breaking changes

### remove the process capability

`capabilities.process` and `Rong.spawn` / `Rong.$` in the home lxapp are removed; delete `process:` from lingxia.yaml, `process = ["lingxia/process", …]` from the native Cargo.toml and `process = ["host/process"]` from the Windows Cargo.toml.

## Writing an lxapp

### expose the browser page primitives on t.automation.browser

`t.automation.browser` drives web pages the way `lxdev browser` does: `snapshot()` returns element refs, actions take `{ ref }` or `{ css, index? }`, wait until the element is actionable, and reject with the failure kind as `code` (`covered`, `stale_ref`, …) plus details in `data`. New: `selectOption`, `check`/`uncheck`, `setInputFiles`, `hover`, `drag`, `text`, `console`, and element/full-page/annotated `screenshot`. Specs that expected `click` to resolve to `null` now get a result object; the selector-only option types are gone.
