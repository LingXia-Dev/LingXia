# LingXia 0.14.0

LingXia 0.14 makes native hosts more product-owned: adaptive tab navigation,
semantic native chrome, host-defined product commands, project upgrades, and a
credential wallet for signed distribution.

## Breaking changes

### 迁移 trusted browser、DisplayLanguage 与 Settings 集成

自定义 browser WebUI 现在必须声明 `controlProtocolVersion: 3`，并使用 RequiredV3
document session。DisplayLanguage 已迁到 preference/state 合同，桌面 Settings 入口改为静态
`settingsDestination`；旧 API 与 route 没有 compatibility alias。

### Use one icon per tab item

`tabBar.items[].selectedIconPath` and the matching `lx.tabBar.update()` field
have been removed. Delete `selectedIconPath`, keep the monochrome `iconPath`,
and let the host apply the selected tint and indicator. The CLI now rejects the
removed field.

### Keep one fixed launch face; use a campaign for runtime art

The configured `splash.image` is now one fixed brand face in every appearance,
matching the frame the OS can render before the process starts. Runtime-selected
art is a separate, skippable campaign: migrate `HostAddon::select_splash` and
`SplashChoice` to `select_campaign` and `CampaignChoice`. A late campaign choice
is dropped rather than delaying a ready home page.

### Browser hosts must provide their web UI

`capabilities.browser: true` now requires `browser.webui`. Run
`lingxia browser-shell eject`, customize the generated browser lxapp, and point
`browser.webui.path` at it. The old fallback named an npm package that was never
published.

### Move signing credentials to the identity wallet

Apple and Harmony credentials are now managed by `lingxia auth login`, selected
by project identity, and diagnosed with `lingxia auth status`. The retired
`LINGXIA_ASC_*` and `LINGXIA_APPLE_NOTARY_*` variables now fail with their
replacement names; CI should provide the complete `LINGXIA_APPLE_KEY_PATH`,
`LINGXIA_APPLE_KEY_ID`, and `LINGXIA_APPLE_ISSUER_ID` group, plus
`LINGXIA_APPLE_TEAM_ID` when required.

## Highlights

### Adaptive tab bars support up to ten destinations

An lxapp may declare 2–10 tab items. Phone hosts keep the first four visible and
fold the rest into **More**; desktop and tablet hosts show the full list. Folded
pages load on first selection, so a ten-tab app does not warm every page at
startup.

### Hosts can align native chrome with the page floor

`theme.light.pageBackgroundColor` and `theme.dark.pageBackgroundColor` tell the
host what the lxapp paints behind its content. Native transition canvases,
pull-to-refresh edges, sidebars, and window chrome can now meet a tinted page
without a system-colored seam.

### Shipped products own their command surface

`HostAddon::install_product_cli` registers product-specific commands, while
`install_host_apis` registers their control namespaces before services start.
Agents invoke the product executable with `--cli`; LingXia no longer generates
a separate launcher or product skill.

### Projects can move to the installed LingXia line

`lingxia upgrade` updates npm ranges, native crate requirements, platform SDK
pins, and lockfiles together. Builds report project/CLI line drift without
failing, and `lingxia upgrade --check` prints the pending plan for automation.

### iOS hosts can package Packet Tunnel extensions

An `ios/PacketTunnel/Info.plist` plus a SwiftPM executable product named
`PacketTunnel` opts into `.appex` packaging. LingXia derives the extension
bundle ID and supports separate extension entitlements and provisioning.

## Important fixes

- `lingxia dev` and `lingxia upgrade` find the published macOS Runner again.
- HarmonyOS SDK builds no longer reference a removed settings icon.
- Android launch orientation is fixed before the home page opens.
- Tab overflow selection and badges now stay consistent across Android, Apple,
  HarmonyOS, Windows, and Runner device shapes.
- Logic-disabled surface pages load correctly.
