# LingXia 0.29.0

On macOS and Windows, lxapps and browser tabs now share one side panel, and
content moves freely between it and the main area. Host apps can explain a
permission before the system asks for it on Android, iOS and Harmony. WebView
pages play media with plain `<video>` and `<audio>`, including large local
files, so the inline native island is gone. `@lingxia/test` registers tests
with `test()`, matching its files, its command and Playwright. macOS DMGs get
a real drag-to-install window, built without Finder. Host apps rebuild against
the 0.29.0 SDK and native library together.

## Breaking changes

### The inline native island is removed

`LxNativeRoot` and its node components (`LxVideo`, `LxNativeView`,
`LxNativeCover`, `LxNativeText`, `LxNativeButton`, `<lx-native-root>`,
`<lx-video>`) are gone with no alias, along with the
`registerInlineNativeComponents` and `compileInlineNative*` helpers.

- In a WebView page, play media with plain HTML `<video>` and `<audio>`. The
  page CSP now allows `media-src` from `lx:`, `lingxia:`, `data:`, `blob:` and
  any https origin, and `lingxia build` no longer rejects Web media.
- For native-player video (rotation, loop, autoplay, ended events), use
  `LxMediaSwiper` with video items.

### `spec()` is now `test()`

`@lingxia/test` exports `test` instead of `spec`, with no alias. Methods keep
their names. Generated ids and the keys in `report.json` do not change.

- Change `import { spec } from '@lingxia/test'` to `import { test }`, and every
  `spec(`, `spec.skip(`, `spec.configure(` and so on to `test(`, `test.skip(`,
  `test.configure(`.
- `SpecOptions`, `SpecBody`, `SpecApi`, `SpecRequirements` and `SpecStart` are
  `TestOptions`, `TestBody`, `TestApi`, `TestRequirements` and `TestStart`.
- `DEFAULT_SPEC_TIMEOUT_MS` is `DEFAULT_TEST_TIMEOUT_MS`.

### Asides group into two slots

Asides used to be grouped by engine into `lxapp`, `browser` and `native`. They
are now `panel` (lxapps and browser tabs in one region) and `native` (the
terminal), and an expanded window admits two. Slot APIs still accept `"lxapp"`
and `"browser"` as names for the panel slot.

- `SurfaceLayoutAsideSlot.kind` in lx automation is `'panel' | 'native'`.
  Compare with `'panel'` where tests matched `'lxapp'` or `'browser'`.
- In Rust, `SlotKind::Lxapp` and `SlotKind::Browser` are `SlotKind::Panel`.
- The Windows contract's `ASIDE_LXAPP_PANEL_ID` and `ASIDE_BROWSER_PANEL_ID`
  are `ASIDE_PANEL_ID`.

### Windows CLI tools are x64 only

Windows CLI releases no longer include Arm64 binaries, and Windows 11 on Arm
runs the x64 build under emulation. If you have a native Arm64 CLI installed,
rerun the installer to switch to x64.

## One side panel on desktop

lxapp pages and browser tabs sit in one docked region with one tab strip, in
the order they were opened, on macOS and Windows.

- **Move content both ways.** "Open in Side Panel" moves an lxapp or a browser
  tab out of the main area, and "Open in Main Area" moves it back. You can also
  drag a sidebar group onto the main's edge, or drop a side panel tab on the
  sidebar. A moved lxapp keeps its pages and state, and a moved browser tab
  keeps its page without reloading. The home lxapp stays in the main area.
- **One menu per row.** Every main-area row opens the same menu from "···" and
  from right-click: what the content offers, "Open in Side Panel", the close
  actions, and Uninstall last. Every side panel tab has its own menu too.
- **A single item gets a plain header** with its icon, name, "···" and ✕, at
  the same height as the tab strip, so the region does not jump when a second
  one arrives. Tabs share a narrow strip and overflow instead of vanishing.
- **A panel stays reachable.** A panel that is collapsed, or hidden because
  the window is too narrow, keeps an edge handle. The handle and Cmd+Option+\
  (Ctrl+Alt+\ on Windows) bring it back, as an overlay when there is still no
  room to dock.
- **The Windows sidebar is resizable.** Drag its inner edge between 148 and
  400, or below 128 to fold it to the icon rail; the choice is remembered. The
  default expanded width is now 148 on every platform.

A new aside opened from Logic without an edge now joins the side panel's
current edge instead of always opening on the right.

## Gate system permission prompts

`Lingxia.setPermissionGate` lets a host explain a permission, or decline it,
before the system prompt appears, with the same shape on Android, iOS and
Harmony. See the host app SDK docs for the types on each platform.

- `beforePrompt` runs each time an lx API needs a permission it lacks, and
  never once it is granted. The host calls `prompt.proceed()` or
  `prompt.deny()`, and `afterPrompt` reports the outcome.
- `prompt.blocked` means the system will not ask again, so the host can guide
  the user to Settings. On Harmony, `proceed()` opens the system re-grant sheet.
- Prompts are gated one at a time. Camera, scanner, media library, location,
  Wi-Fi and notification prompts all pass through the gate, as do iOS
  save-to-album and `lx.getLocation`.
- On Android, an undecided prompt is denied when its activity is destroyed.
- On iOS and Harmony every denial is permanent, so the outcome is the
  denied-permanently value.

## Open content in a chosen region

The control methods `lxapp.open` and `browser.open` take
`placement: { region: "main" | "aside" }` and report
`surface: { id, region, presentation }`.

- An lxapp already open on the requested channel is shown where it is, rather
  than failing with a surface conflict when it is an aside.
- `browser.open` with `aside` opens the URL as a side panel page owned by
  `owner`, by default the home lxapp, or in the compact aside browser on a
  compact window. A placement next to `tab_id`, or an owner without the aside,
  is rejected.
- `shell_presence(appid)`, exported from `lingxia`, reads an app's region, its
  surface, how that surface is on screen, and the window's size class at call
  time.

## macOS DMGs

`lingxia package --dmg` now lays out the window: a background with an arrow
from the app to Applications, at 1x and 2x.

- `macos.dmg.background` in `lingxia.yaml` replaces it with a 660x400 PNG and
  an optional `@2x` sibling.
- The layout is written directly into the image, so packaging works on a
  headless CI runner and needs no Automation grant. A layout failure now fails
  the build rather than printing a warning.

## Fixes

- **Large local media.** `lx:` answers Range requests and streams file bodies
  on every platform. Large local videos failed to load on Windows and memory
  grew by gigabytes.
- **macOS window close.** The close button now hides the main window and the
  app keeps running in the Dock, with or without a tray. ⌘Q quits, and a Dock
  click shows the window again. Windows is unchanged.
- **macOS updates.** A host update whose executable has no slice this Mac can
  run is refused and the installed version stays, instead of leaving an app
  that could neither launch nor update.
- **Brand switch.** Apps drained by a brand switch leave the macOS and Windows
  sidebars instead of keeping their rows.
- **Sidebar icons.** Icons are decoded from their bytes, so a WebP logo at a
  URL ending in `.png` no longer disappears on macOS 26 or Windows.
- **Windows side panel.** Collapsing or expanding it no longer freezes for 10
  seconds and leaves the layout half applied.
- **Windows Runner.** Device frames, their chrome and the info sheet scale
  correctly on high-DPI displays, and toolbar controls stay apart on narrow
  frames.
- **Runner.** Hosts no longer show the dev port mark meant for product hosts.
- **iOS tab bar.** A tap on the selected tab's icon reaches the tab, so More
  reopens every time.
- **`lx.cloud.invoke`.** Calls no longer hit a stack limit on Harmony or, with
  an object payload, on a debug Android build.
- **Timers.** Scheduling many tasks at once, such as 10,000 `setTimeout` calls,
  is no longer quadratic.
- **Downloads.** A refused connection fails at once instead of retrying.
- **`lingxia build --env`.** An env with no `lingxiaServer` now builds, and
  `app.json` omits the field.
- **JUnit output.** A `test.fail` that failed as declared is written as
  `<skipped type="xfail">` and counted as skipped, not passed. The run still
  passes.

## Already in CLI 0.28.1

If you are coming from CLI 0.28.0, these also apply:

- `lingxia auth runner`, `lingxia dev --runner` and
  `lingxia dev --display-language` are removed. Save the server with
  `lingxia auth login lingxia --env <env> --server <url>`, and change a running
  Runner with `lxdev runner set`, for example `--language zh-CN`.
- `macos.arch: arm64|x86_64|universal` in `lingxia.yaml` declares what a
  packaged macOS app supports, and `--macos-arch` overrides it for a build.
  `lingxia publish` refuses a package missing a declared architecture.
- `lingxia upgrade` updates every published LingXia crate, so a project no
  longer locks two copies of the runtime.
