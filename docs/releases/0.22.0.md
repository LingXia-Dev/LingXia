# LingXia 0.22.0

## Breaking changes

### require HarmonyOS 6.1.0 (API 23)

BREAKING: LingXia on HarmonyOS now requires HarmonyOS 6.1.0 (API 23). Existing Harmony hosts must raise `targetSdkVersion` and `compatibleSdkVersion` in `harmony/build-profile.json5` to `6.1.0(23)` and build with DevEco / Command Line Tools 6.1.0 or later; devices below HarmonyOS 6.1.0 can no longer install LingXia apps.

## Writing an lxapp

### theme the native pull-to-refresh spinner

Every shell's pull-to-refresh indicator takes the host
theme's accentColor (else mutedForegroundColor) and announces refresh
start and end; mobile content pulls down with a spinner, while desktop
shows a bar along the top of the page without moving it. F5 / Ctrl+R /
⌘R refresh pages that enable pull-down refresh.

## Embedding a host app

### sign and provision HAPs from the Windows CLI

Harmony provisioning and HAP signing now work from the
Windows CLI, so Windows build machines can produce store-ready HAPs.
