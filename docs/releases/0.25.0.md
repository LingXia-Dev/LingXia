# LingXia 0.25.0

## Breaking changes

### hand package outputs to publish, store, and install through a dist manifest

BREAKING: `lingxia package` now records its outputs in `dist/<platform>/manifest.json`, and `lingxia store submit` uploads only what that manifest lists: run `lingxia package` before submitting (an artifact copied into `dist/` by hand is no longer picked up). Publish a fresh build with `lingxia publish dist/<platform>`; `--dry-run` prints the exact file for pre-upload checks. Windows packaging no longer writes `*-artifacts.json`; read `manifest.json` instead.

### publish what the package says, from anywhere

BREAKING: `lingxia publish` takes a host package as its argument: `lingxia publish dist/macos/App-1.2.3-macos.zip --lingxia-server <url>`. `--package-path`, `--platform`, and automatic `dist/` lookup are gone, and publish no longer reads `lingxia.yaml`: pass `--lingxia-server` (or save one with `lingxia auth login lingxia --server`). The published id, version, env, and platform come from the package, so a host package publishes from any directory.
