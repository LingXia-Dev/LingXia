# LingXia 0.20.0

## Breaking changes

### identify pages by instance on every platform

BREAKING — pages are identified by instance (the webview tag) across the platform contract. Swift hosts: `LxAppNavigateRequest` and `LxAppControllerEvent.didNavigate` gain `pageInstanceId`; iOS `LxAppViewController.navigate` / `openLxApp` / `handleNavigation` take the page instance; `LxApp.startPullDownRefresh` / `stopPullDownRefresh` take a webtag. Kotlin hosts: `LxApp.open(appId, path, sessionId)` is replaced by `LxApp.show(appId, webtag, sessionId)` (the host entry `LxApp.open(appId, path)` stays); `LxApp.navigate` and `LxAppActivity.openLxApp` drop their path argument; `LxAppPullToRefresh.startPullDownRefresh` / `stopPullDownRefresh` take a webtag. Rust platform implementors: `AppRuntime::show_lxapp` takes a `ShowLxApp` request and `navigate` takes `(appid, webtag, animation)`; `UIUpdate` loses its appearance and launch-splash methods to the new `Appearance` and `LaunchFace` traits; `PullToRefresh` takes a webtag; `SurfaceRequest` carries `SurfaceContent::Page { webtag }` or `SurfaceContent::Url { url }` and `owner_session_id` instead of `path`, `session_id` and `page_instance_id`. The native library and the platform SDK must come from the same build: JNI and FFI names changed on both sides.
