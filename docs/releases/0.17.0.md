# LingXia 0.17.0

## Breaking changes

### require app.packageId

`app.packageId` is now the host's OS identity on every platform, and the build
fails without it. Copy the reverse-DNS onto `app.packageId`, and keep
`android.packageId` / `ios.bundleId` / `macos.bundleId` / `windows.appId` /
`harmony.bundleName` only where that store listing differs. The env suffix still
applies.

### drop the preview publish channel

An lxapp package line is `release` or `draft`. Replace `--channel preview` with
`--channel draft` for testers, and `channel=preview` in App Link open URLs with
`channel=draft`. The host env is unchanged: a staging server is still a `dev`
env.

### make store submission upload-only

`lingxia store submit` uploads and stops there. `--draft` is gone, and so are
the review-submit and rollout paths behind it (AGC app-submit, Play
`completed`, Partner Center commit, Xiaomi/OPPO/Honor push). Submit for review
in the store console.

### split the Android SDK into core, camera, and scanner artifacts

The SDK publishes four artifacts: `lingxia-core` (minSdk 21 — runtime, bridge,
playback, media preview/picking), `lingxia-camera` and `lingxia-scanner`
(minSdk 23), and `lingxia`, now the complete SDK at minSdk 24. Generated hosts
default to core and add capabilities explicitly:

```kotlin
implementation("io.github.lingxia-dev:lingxia-core:$lingxiaSdkVersion")
implementation("io.github.lingxia-dev:lingxia-camera:$lingxiaSdkVersion")
```

Keeping the `lingxia` coordinate means raising the host to minSdk 24; to stay on
21/22, select core and omit the optional modules. See
`lingxia-sdk/android/README.md`.

## Writing an lxapp

### open login new-windows in the system browser

A URL-callback surface keeps same-window `https` so an identity provider's
redirect hops stay in the login sheet, but `target=_blank` and `window.open` now
hand `http(s)` to the OS browser. The policy is the same on every platform.

### recover pages after renderer termination

A page whose WebView renderer is killed now reloads instead of staying blank,
scoped to the lxapp being shown.

### keep the WebView out of the Android gesture zone

On Android, a page that hides the TabBar no longer draws the WebView into the
gesture-navigation zone, so its bottom controls stay tappable. Opaque on-screen
TabBars still own that strip, and immersive layouts stay edge-to-edge.

## Embedding a host app

### localize productName with a productNames map

`app.productName` stays a plain string and remains the required default.
Localize it with an optional sibling map, without repeating the default:

```yaml
app:
  productName: My App
  productNames:
    zh-CN: 我的应用
```

The launcher follows the **system** language; window titles, tray labels, and
`lx.getAppBaseInfo().productName` follow `lx.app.displayLanguage` (`auto` =
system).

### apply app.productVersion to every platform package

`lingxia build` stamps `app.productVersion`, and a derived version code, into
the package on every platform. Per-platform project files stay placeholders, so
a version change no longer dirties the git tree.

### expose window caption buttons to accessibility queries

macOS and Windows report close/minimize/maximize as named accessibility
controls, so automation invokes them by keyword (`name:close`) instead of
driving a pointer.

## CLI and CI

### package the artifacts the stores accept

`lingxia package` writes a Harmony `.app` through `hvigor assembleApp`, because
AppGallery rejects a raw HAP, and an App Store-signed iOS `.ipa` without
needing a connected device. Harmony HAPs are signed with the id the package
actually carries, so `lingxia dev --env dev` installs and launches the `.dev`
bundle.

### wait for store processing, in JSON

`lingxia store submit` and `store status` take `--wait` (with `--timeout` and
`--poll-interval`) so CI can gate on Apple and Harmony processing, and `--json`
for one machine-readable result on stdout with progress on stderr. Processing
complete is not review approval. After a timeout, resume with `store status
--submission-id <id>` instead of uploading again.

### keep tool upgrades out of project changes

`lingxia upgrade --cli-only` moves just the `lingxia` binary, leaving `lxdev`,
the Runner, project dependencies, and the agent skill alone. `--skip-skill`
(also `LINGXIA_SKIP_SKILL`) skips skill synchronization on any command, for CI
images that must not rewrite it.
