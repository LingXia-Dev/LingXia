# LingXia 0.15.0

LingXia 0.15 gives every host a registry-backed identity for lxapps — name,
icon, and whether the app may open — and lets a product set its own display
language. An lxapp can now tell a phone from a desktop even inside the
Runner. Tab navigation, macOS page chrome, and CLI upgrades pick up the
fixes that landed with that work.

## Breaking changes

### Read the lxapp icon from the registry, not the package

`lxapp.json`'s `icon` field is no longer read. An lxapp's on-screen icon
comes from the registry record its host's `LxAppRegistryProvider` supplies,
cached locally and addressed by the icon URL. A manifest that still carries
`icon` keeps parsing, but the value is ignored: a host with no registry
provider draws the default LingXia mark instead.

Apple SDK hosts must replace `getLxAppInfo(appId).icon`, which is gone, with
`getLxAppDisplayIconPath(appId)`.

### Address tab bar items by page name

`tabBar.items[].pagePath` is gone. Address a tab by the configured
`pages[].name` in `page`, the same token `lx.switchTab({ page })` takes. The
CLI rejects the old field.

## Highlights

### Hosts own name, icon, and open-gate from the registry

Register an `LxAppRegistryProvider` to supply one record per app: display
name, icon URL, and status. `Suspended` and `Maintain` block opening and
report why as data; `Delisted` stays runnable if already installed. Artwork
is cached by URL, so change the URL when the image changes. Sidebar, About,
and expanded chrome repaint when the record refreshes.

### Home lxapps can set the host display language

`lx.app.setDisplayLanguage('auto' | 'en-US' | 'zh-CN')` persists the product
language from the home lxapp. Native hosts can use
`lingxia::app::set_display_language`. Guest lxapps inherit the setting and
cannot change it. A Runner `--display-language` remains a session override.

### `isMobile()` / `isDesktop()` answer the form factor

`isDesktop()` no longer means "macOS or Windows". It answers the machine
class: a phone frame in the Runner reports `isMobile()`, and a narrowed
desktop window stays desktop. Tablets count as mobile. `usePlatform()`
exposes both. Switching the Runner to a frame of a different class
re-serves open pages so they boot with the new value.

### macOS pages get a real pull-to-refresh

A page that declared `enablePullDownRefresh` now has the trackpad and wheel
gesture on macOS, with the same arm distance and indicator as iOS and
Android. The native-component overlay follows the page offset, so hit-testing
stays on the pixels the user sees.

### The CLI keeps the agent skill and templates current

Every `lingxia` run reconciles the installed skill against the binary that
is running. `lingxia skill` is gone: `new` and `upgrade` create the install,
and `version --verbose` reports its state. Template sources refresh in the
background and are compared by content before staging.

### Tests can count the `lx.*` APIs a spec actually reached

`lxapp.eval({ captureCalls: true })` records the member paths the evaluated
script touched, so a coverage report can tell an exercised API from a
claimed `covers` entry. Existing eval callers are unchanged: the capture is
opt-in.

## Important fixes

- iOS tab overflow reopens after picking a folded tab, and dismisses when the
  strip is rebuilt or torn down.
- Android refreshes an open overflow panel with tabbar state, sizes the tab
  bar for the lxapp that is opening, and keeps the pull-to-refresh indicator
  through an lxapp switch.
- HarmonyOS preserves hyphens in page show routes.
- macOS stops the tab-bar "More" panel flashing the window, paints the page
  cover with the page's own colour, and no longer plays a navigation as two
  animations.
- Windows About and sidebar rows read name and icon from the registry.
- `lingxia upgrade` retries a pinned SDK fetch the cache is still missing,
  restores Apple package manifests after builds, and trusts the platform's
  root certificates.
- The Runner's simulated appearance reaches the lxapp, and capsule action
  icons match the built-in size.
