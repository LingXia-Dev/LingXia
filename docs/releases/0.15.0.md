# LingXia 0.15.0

## Breaking changes

### delete the packaged lxapp icon and read every host's icon from the registry

`lxapp.json`'s `icon` field is no longer read. An lxapp's icon
now comes from the registry record its host's `LxAppRegistryProvider` supplies,
cached locally and addressed by content hash. Delete the field from your
manifest — a manifest that still carries it keeps parsing, but the value is
ignored, so a host with no registry provider draws the default LingXia mark
instead. Apple SDK hosts must replace `getLxAppInfo(appId).icon`, which is
gone, with `getLxAppDisplayIconPath(appId)`.

### address tab bar items by page name

tabBar.items[].pagePath is gone. Address a tab by the
configured pages[].name in page, the same token lx.switchTab({ page })
takes. The CLI rejects the old field.

## Embedding a host app

### let the home lxapp set the host display language

Home lxapps can now persist the host display language with lx.app.setDisplayLanguage('auto' | 'en-US' | 'zh-CN'); native hosts can use lingxia::app::set_display_language.
