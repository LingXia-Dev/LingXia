# LingXia 0.26.0

An lxapp opened as a desktop aside now behaves like a complete app in its
panel, on macOS and Windows: its own page stack, navigation bar, tabBar and
floats, a Maximize control, a restore handle when collapsed, and page
lifecycle on collapse. `SurfaceContext.aside` is renamed `canDock`.
`lingxia dev --env prod` no longer starts a template's local Worker, which
changes the dev companion protocol. `lingxia dev listen` develops an lxapp on
an installed device app, and `lxdev network capture` replaces `record` with
JSON and HAR output of real traffic. Host apps rebuild against the 0.26.0 SDK
and native library together.

## Breaking changes

### `SurfaceContext.aside` is now `canDock`

- `lx.surface.watchContext` in Logic, the `canDock` key Views receive, and
  `useLxHost().canDock` in the bridge, React and Vue replace `aside`. Replace
  `.aside` with `.canDock`; there is no alias.
- The value is unchanged: whether `as: 'aside'` docks beside the main right
  now. It does not say where the lxapp is shown.
- An older host sends no `canDock`, which reads as `false`.
  `lx.supports('surface.aside')` was never a feature query and still returns
  `false`.

### Collapsing a docked lxapp aside fires page `onHide`

Collapsing fires page `onHide` on the page the aside was showing, and
restoring fires `onShow`. The lxapp stays loaded and App `onHide` does not
fire. Code that treats page `onHide` as "the user left the app" should check
App `onHide` instead.

### The dev companion is told the session env

- `lingxia dev --env prod` no longer runs a template's local Worker: Functions
  call the deployed prod Worker. Before, auth went to prod while every
  Functions call went to the local Worker.
- `session.prepare` carries a required `env`, and companions speak protocol
  version 3. The CLI, LingXiao and the fusheng template must be upgraded
  together; an older companion is refused with "Unsupported development
  companion protocol version 2". Run `lingxia template update`.
- `--mock all` needs `--env dev`: mocked Functions run in the local companion.
  `--mock none` works in any env.

### `lxdev network capture` replaces `record`

- `lxdev network capture start` / `capture stop <requests.json> [--har <file>]`
  replace `lxdev network record`, with no alias. Stop writes the request JSON
  for an agent and an optional HAR for a viewer; it no longer writes a
  scenario.
- Captures and `lxdev test --record-network` record what reached the
  network: lx transfers, redirect hops and, with `--all`, host traffic, each
  with its owner appid. Recorded scenarios change shape: a redirect chain is
  one rule, a blocked request replays as `abort`, and a body the app never
  finished reading is noted, not replayed. Re-record scenarios that relied on
  the old shape.
- Secrets in observed bodies, proxy credentials and redirect targets are
  masked.

### `--skip-native` is removed

`lingxia build`, `package` and `dev` no longer take `--skip-native`. Drop it
from scripts; an unchanged native library is not recompiled.

## Desktop asides

On macOS and Windows, an lxapp opened with
`lx.shell.openApp(id, { as: 'aside', edge })`:

- **Keeps its page stack and floats in the aside.** `navigateTo` and
  `navigateBack` from its Logic push and pop inside the aside, and a float it
  opens anchors to it. Keyboard focus moves with the aside.
- **Has a navigation bar** under its tab strip. At the root of its own stack
  the bar takes no height unless Home is offered; after a push it shows Back
  and the title. Home is offered when an lxapp (aside or main) lands on a page
  that is not its initial route.
- **Draws its tabBar** as a 28pt segmented row on a tab page, which becomes a
  pop-up (macOS) or a menu (Windows) below 240pt. An item without text is
  named after its page. There is no manifest option.
- **Can be maximized** from its tab strip, covering the main area without
  changing the role. The main keeps its frame and lifecycle underneath. It
  restores on the second click, on any intent to see main (a sidebar entry,
  the active group header, a main switch, `openApp(..., { as: 'main' })`), on
  Escape (macOS), and when the slot collapses or loses its last tab. The
  browser aside slot and docked terminals maximize the same way.
- **Leaves a restore handle** at its edge when collapsed.
  Cmd+Option+\ (macOS) or Ctrl+Alt+\ (Windows) collapses or restores it; AltGr
  typing is not taken. A collapsed aside pauses its page's native components.
- **Has minimum sizes:** side asides drag no narrower than 240pt, top and
  bottom ones no smaller than 180pt.
- On macOS, Backspace is Back for the focused region only when the page leaves
  it unhandled, so text fields keep it.

Fixes along the way:

- Maximize, sidebar clicks and restore no longer leave the main black or as a
  thin strip (macOS).
- A layout plan that arrives after a newer commit is dropped, so a maximize no
  longer snaps back.
- A browser aside opened on any edge appears and closes with its tab; a
  surface whose WebView never arrives is given up instead of blocking later
  layouts (Windows).
- macOS chrome icons decode downsampled, fixing an ImageIO crash on Intel
  Macs. The incoming main's sidebar group expands on every switch.

## Developing on a device

- `lingxia dev listen`, in an lxapp directory, develops that lxapp on an
  installed host app: with `-p <platform> --port <port>` it is the session the
  app dials; without `--port` it attaches to a running host session. Saves
  rebuild and reload the lxapp in place, and sessions keep presented lxapps
  open across relaunches. See `docs/skill/cli/dev-reload.md`.
- A host built for `lingxia dev` pulls lxapps from the dev bundle server on
  first open and on a dev restart. Product builds compile none of it.
- iOS dev builds reach the Mac by its Bonjour name, with the build-time
  address as fallback, so a DHCP change needs no rebuild.
- `lingxia dev stop` reaches a named session from any directory.

## Apple signing and the App Store

- `lingxia auth login apple --mode app-password` stores an Apple ID with an
  App-specific password, and `lingxia store submit --platform ios|macos`
  uploads with it when the team has no App Store Connect API key. `--wait` and
  `store status` still need the key.
- Password sessions sign App Store IPAs.
- `lingxia auth status` shows which team signs and why, and what each team can
  sign, upload and read (`--json`: `appleTeams[].capabilities`).
- A `--env dev` package is submitted to the app with the `.dev` bundle id;
  create that app in App Store Connect first.
- iOS builds compile the app icon and ship the launch storyboard without the
  iOS simulator runtime: the CLI prepares an APFS clone of Xcode under
  `~/.lingxia/apple/actool` once per Xcode version, and ships the storyboards
  precompiled. An App Store IPA whose asset catalog cannot be compiled now
  fails instead of being rejected later by App Store Connect.

## Versions

- `minRuntime` is a major.minor build target: a patch never refuses a
  package. The CLI builds for `minRuntime` lines from 0.25 up to its own line,
  and below that names the CLI to use and `lingxia upgrade`.

## Other fixes

- iOS and Harmony: one edge swipe backs out of a guest lxapp.
- Android: native pickers, overlays and the preview player settle correctly;
  App show fires when returning to the caller.
- `onShow` replays after an in-place restart, and only for an opened app.
- View-call cancellation is scoped to its page, and a native close clears page
  history.
- `lx.shell.openApp` focuses the lxapp it opens and raises the host only for
  that explicit activation.
- The browser keeps the opening load as its only trusted navigation and
  follows native selection for product tabs.
- `lingxia publish` publishes a host project's bundles even with a root
  `lxapp.json`.
