# LingXia 0.26.0

## Breaking changes

### tell the companion the session env

`lingxia dev --env prod` no longer runs a template's local Worker: Functions call the deployed prod Worker. This changes the dev companion protocol, so the CLI, LingXiao, and the fusheng template must be upgraded together; an older companion is refused with "Unsupported development companion protocol version 2". `--mock all` now needs `--env dev`.

### rename SurfaceContext.aside to canDock

BREAKING: `SurfaceContext.aside` (from `lx.surface.watchContext`) and `useLxHost().aside` are renamed `canDock`; replace `.aside` with `.canDock`. The value is unchanged: whether `as: 'aside'` docks beside the main right now, not where the lxapp is shown. Requires a host built from this release; an older host sends no `canDock`, which reads as false.

### remove --skip-native

`--skip-native` is removed from `lingxia build`, `package`, and `dev`. Drop it from scripts; an unchanged native library is not recompiled.

### record real network traffic from Rong's network observer

`lxdev network record` and `--record-network` now record what
reached the network: lx transfers, redirect hops, and (with `--all`) host
traffic, each with its owner appid. Recorded scenarios change: a redirect
chain is one rule, a blocked request replays as `abort`, and a body the app
never finished reading is noted, not replayed. Re-record scenarios that
relied on the old shape.

## Writing an lxapp

### fire page onHide/onShow when the lxapp aside collapses and restores

Collapsing a docked lxapp aside now fires page `onHide` on the page it was showing, and restoring it fires `onShow`. The lxapp stays loaded. Code that treats page `onHide` as "the user left the app" should check App `onHide` instead.

## CLI and CI

### ship the iOS launch storyboards precompiled

iOS builds always include the configured launch storyboard, with no iOS simulator runtime installed: the CLI ships it precompiled instead of running `ibtool`.

### compile iOS asset catalogs without the simulator runtime

iOS builds compile the app icon without the iOS simulator runtime: on first need, `lingxia` prepares an APFS clone of Xcode under `~/.lingxia/apple/actool` (once per Xcode version).

### show what each Apple team can sign, upload, and read

`lingxia auth status` shows whether each Apple team can sign, upload, and read build status, and `--json` adds `appleTeams[].capabilities` (`sign`, `upload`, `buildStatus`).

### an App Store IPA requires its compiled app icon

`lingxia package --platform ios` fails for every env when the asset catalog cannot be compiled (for example without the iOS platform installed), instead of producing an IPA that App Store Connect rejects.

### upload to App Store Connect with an App-specific password

`lingxia auth login apple --mode app-password` stores an Apple ID with an App-specific password, and `lingxia store submit --platform ios|macos` uploads with it when the team has no App Store Connect API key; `--wait` and `store status` still need the key.

### submit a dev Apple package to its dev app

`lingxia store submit --platform ios|macos` uploads a `--env dev` package to the app with the `.dev` bundle id; create that app in App Store Connect first.
