# @lingxia/terminal-settings

The Settings lxapp for LingXia's desktop terminal. It lets users choose fonts,
color schemes, and light/dark appearance through its capability-scoped
`lx.terminal` Logic API.

Products enable `capabilities.terminal` and declare this package as an ordinary
`resources.bundles` lxapp with app id `app.lingxia.terminal-settings`. For
local development, use a project-relative `path` to this directory instead of
the npm `package` source.
