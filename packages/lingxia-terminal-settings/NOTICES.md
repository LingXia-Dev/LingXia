# Terminal settings theme notices

The terminal settings package redistributes these color schemes. The full
license text for each scheme ships beside its source data under `themes/`.

| Theme | Author | Upstream | License |
|---|---|---|---|
| Dracula | Dracula Theme | https://github.com/dracula/dracula-theme | MIT |
| Nord | Sven Greb | https://github.com/nordtheme/nord | MIT |
| Solarized Dark | Ethan Schoonover | https://github.com/altercation/solarized | MIT |

The built-in default themes are part of LingXia and are not third-party assets.
