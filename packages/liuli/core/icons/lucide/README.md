# Lucide icons

The SVG files in this folder are from Lucide 1.28.0 (https://lucide.dev), unchanged, under the ISC
licence in `LICENSE`. `../icons.json` gives each one the name Liuli's components ask for;
`scripts/icons.mjs` turns them into the modules under `src/Icon/`.

All files come from one Lucide version, the one named here and in `../icons.json`. To update, replace
every file from the new version, change the version in both places, and run `npm run generate`.
